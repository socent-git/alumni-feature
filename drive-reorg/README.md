# SocEnt Drive reorganisation

Two Apps Scripts with a Claude analysis step in between.

```
Script 1 (extract)  ->  Schema sheet  ->  Claude (prompt in 03)  ->  Mapping tab  ->  team review  ->  Script 2 (dry run -> run)
```

| File | What it is |
|---|---|
| `01_extract_schema.gs` | Script 1. Writes folder names, hierarchy and file counts (no contents) to a new Google Sheet with Schema, Tree and Mapping tabs. Flags duplicates, empty folders, years in names, whitespace and vague names. |
| `02_reorganise.gs` | Script 2. Builds the 00-07 skeleton and applies the Mapping tab: MOVE / MERGE / RENAME / SHORTCUT / CREATE / SKIP. Dry run by default, never deletes, can be re-run after a timeout. |
| `03_claude_analysis_prompt.md` | Prompt to paste into Claude with the Schema output. It encodes the agreed structure and naming rules. |
| `draft_mapping_top_level.csv` | First-pass mapping for the 93 top-level folders of the SocEnt shared drive, as of 2026-10-27, with H/M/L confidence. Generated by `build_draft_mapping.py`. |

## Run order

1. script.google.com > New project. Add both `.gs` files. Services > add **Drive API**.
2. `extractSchema()`. The log prints the sheet URL.
3. Give Claude the Schema tab with `03_claude_analysis_prompt.md`. Paste its mapping into the **Mapping** tab, or start from `draft_mapping_top_level.csv`.
4. Team review: fix every `L` row and every `YYYY-MM` / `MM` placeholder in New Name.
5. In `02_reorganise.gs` set `SPREADSHEET_ID`. With `DRY_RUN: true`, run `buildSkeleton()`, then `runReorganisation()`. Read the Result column.
6. Set `DRY_RUN: false`, then run `buildSkeleton()` and `runReorganisation()` again. If it stops on the time limit, run it again.
7. Check the `zz_MERGED_*` folders are empty, then delete them by hand.
